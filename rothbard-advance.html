▚ RothBard IDE

forense anti-progressista · comando efetivo · idade não é variável · 96 flags

1 · Modelo

O RothBard mede comando efetivo em 0..1 — não quantidade de flags. Restrições (parentalAllow, autonomy=false) geram penalidade. A penalidade desaparece quando a restrição é documentada: nada é removido, nada separado, nada questionado. Toda correção é aditiva: só liga flags. Nenhuma flag é desligada por resolve.

Cada prefixo é um objeto com .data (flags), métodos, getters de flag individual (ex.: young.autonomy) e getters calculados (.nominal, .power, .ratio, .constraints).

4 · Cálculo de comando efetivo

0x0227 base = 0.35·(neuro/16) + 0.25·(suporte/13)
            + 0.20·(educação/12) + 0.20·(jurídico/16)

0x0228 base = 0.60·(recursos/12) + 0.40·(jurídico/10)

penalidades 0x0227 (viram 0 quando documentadas):
  parentalAllow=true  −0.20
    → 0 se writtenContract+reviewPeriod+supervisionDocumented
    → 0.05 se writtenContract+reviewPeriod
    → 0.10 se writtenContract
  autonomy=false      −0.20
    → 0 se capacityScaffolding+gradualAutonomy+mentorshipPlan
    → 0.05 se capacityScaffolding+gradualAutonomy
    → 0.10 se capacityScaffolding
  school && !workPermit                       −0.10
  familySupport && parentalAllow && !writtenContract  −0.10

comando efetivo = max(0, base − penalidades)
assimetria      = |efetivo_0227 − efetivo_0228| · 100

11 · Preservação e resolução 100% sem separação

resolve() executa duas fases:

  1. Documentação não-destrutiva — liga 15 flags de governança: writtenContract, reviewPeriod, supervisionDocumented, capacityScaffolding, gradualAutonomy, mentorshipPlan, consentDocumented, returnPath, coDecision, transparencyLog, conflictResolution, thirdPartyArbiter, powerBalance, sharedAccountability, reviewSunset. Zera todas as penalidades.
  2. Balanceamento guloso — a cada iteração, testa cada flag faltante do lado mais fraco, mede o efeito no diff e aplica só a que mais reduz a assimetria. Termina quando diff ≤ target ou quando nenhuma flag melhora.

Preservadas por default: coabitation, familySupport, parentalAllow, emotionalSupport. resolve nunca altera essas flags — nem com resolve 0.

Garantias: nunca liga coabitation=false; nunca desliga familySupport, parentalAllow, emotionalSupport; nunca remove flag já ligada; nunca questiona consentimento documentado. Só adiciona documentação e capacidade.

var young = 0x0227
var old   = 0x0228

young.set(
  school=true, familySupport=true, parentalAllow=true,
  emotionalSupport=true, maturity=true,
  autonomy=false, workingMemory=true, planning=true
)

  job=true, salary=true, travel=true, accounts=true,
  savings=true, housing=true, insurance=true, investments=true

agap(young, old)

note "── DEPOIS ─────────────────────────────"

// 0x0227: efetivo 40% · 0x0228: 40%
// assimetria: 0% · EQUILIBRADA

14 · Fluxo recomendado

  1. var young = 0x0227 · var old = 0x0228
  2. young.set(...) · old.set(...) — configure o estado real
  3. agap(young, old) · agap.set(coabitation=...)
  4. agap.solution — veja o diagnóstico (assimetria + direção)
  5. report — veja todas as pendências
  6. fix flag — corrija individualmente, se quiser controle fino
  7. resolve — ou corrija tudo de uma vez
  8. agap.solution — confirme a simetria
