1 · RothBard IDE

Ambiente forense que mede comando efetivo — não quantidade de flags. parentalAllow=true, school=true e autonomy=false são restrições, não capacidades. O sistema calcula: capacidade nominal − penalidades = comando efetivo.

3 · Flags (37 no total)

3.1 · 0x0227 — capacidade (7)

autonomy, discerniment, maturity, consent, legalCapacity, financialLiteracy, digitalLiteracy

3.2 · 0x0227 — suporte (contexto, não soma poder)

family, parentalAllow, emotionalSupport, safetyNet, health

Correção conceitual: parentalAllow=true NÃO é capacidade — é restrição. Significa que a pessoa precisa de permissão. Reduz o comando efetivo.

3.3 · 0x0227 — educação (contexto)

school, workPermit, educationPath

3.4 · 0x0228 — recursos (7)

job, salary, travel, accounts, savings, housing, insurance

3.5 · 0x0228 — jurídico (5)

contractSigning, licenses, creditHistory, taxFiling, businessOwnership

3.6 · agap — governança (10)

coabitation, emancipation, powerBalance, consentDocumented, reviewPeriod, exitStrategy, thirdPartyArbiter, writtenContract, transparencyLog, conflictResolution

4 · Cálculo de comando efetivo

4.1 · 0x0227

capacidade nominal = (autonomy + discerniment + maturity + consent
                    + legalCapacity + financialLiteracy + digitalLiteracy) / 7

penalidades:
  parentalAllow=true          → −2   (precisa de permissão)
  autonomy=false              → −2   (sem autonomia)
  school=true && workPermit=false → −1 (estudante sem trabalho)
  family=true && parentalAllow=true → −1 (governança familiar reforçada)

comando efetivo = max(0, capacidade − penalidades) / 7

4.2 · 0x0228

comando = (job + salary + travel + accounts + savings + housing + insurance
         + contractSigning + licenses + creditHistory + taxFiling + businessOwnership) / 12

4.3 · Assimetria com direção

diff% = |comando_young − comando_old| × 100

0–10%   → EQUILIBRADA
11–25%  → LEVE
26–50%  → MODERADA
51–75%  → ALTA
76–100% → CRÍTICA

Direção explícita: 0x0228 > 0x0227 (padrão típico — adulto comanda) ou 0x0227 > 0x0228 (inverso — capacidade sem recurso).

7 · Sintaxe fix

fix autonomy           // young.grant('autonomy') — remove −2
fix parentalAllow      // young.revoke('parentalAllow') — remove −2 e −1
fix workPermit         // young.grant('workPermit') — remove −1
fix discerniment       // young.grant('discerniment') — +1 capacidade
fix financialLiteracy  // young.grant('financialLiteracy') — +1
fix conflictResolution // agap: mediação + revisão + log
fix writtenContract    // agap: contrato escrito
Regra: flags de restrição (parentalAllow) são revogadas pelo fix. Flags de capacidade e governança são garantidas.

9 · Exemplo

var young = 0x0227
var old   = 0x0228

young.set(
  school=true, family=true, maturity=true,
  parentalAllow=true, autonomy=false, discerniment=false,
  consent=true, health=true, emotionalSupport=true
)
old.set(job=true, salary=true, travel=true,
        accounts=true, insurance=true)

agap(young, old)
agap.set(coabitation=true, writtenContract=true)

agap.solution
// 0x0227: nominal 2/7 · efetivo 0/7 (0%)
// 0x0228: comando 5/12 (42%)
// assimetria: MODERADA · direção 0x0228 > 0x0227
// → limitação estrutural: capacidade existe, comando não

fix autonomy
fix parentalAllow
fix workPermit
fix discerniment

agap.solution
// 0x0227: nominal 4/7 · efetivo 4/7 (57%)
// assimetria: LEVE · direção 0x0227 > 0x0228
