1 · RothBard IDE

Ambiente forense que compara poder de decisão entre dois prefixos sem usar idade. Mede capacidade (0x0227) contra recurso (0x0228), e verifica a governança do vínculo (agap).

4 · Métodos de prefixo

métodoefeito
.set({...})configura flags em lote
.grant("autonomy","consent")liga flags
.revoke("parentalAllow")desliga flags
.reset()zera todas as flags
.missing()lista flags desligadas
.audit()mostra estado por grupo
.flaggetter booleano (ex.: young.autonomy)
.powergetter: quantas flags ligadas (0..15 / 0..12)
.ratiogetter: poder normalizado (0..1)

5 · agap — vínculo

agap(young, old)
agap.set(coabitation=true, emancipation=false, writtenContract=true)

Também aceita agap(young + old). Todos os flags de governança viram getters booleanos.

Métodos

métodoefeito

7 · Sintaxes DSL

7.1 · if clássico

if (agap.coabitation === true) {
  print("nao e recomendado afastar dos pais ou estudos")
} else {
  print("certo, so deixe a autonomia garantida")
}

7.2 · if/catch inline

if coabitation = true.catch(print"nao e recomendado afastar dos pais ou estudos")
else if coabitation = false.catch(print"certo, so deixe a autonomia garantida")

7.3 · when

when autonomy.catch(print"autonomia garantida")
when writtenContract.catch(print"contrato escrito presente")

7.4 · assert (linha isolada)

assert autonomy
assert writtenContract

Verifica a flag em qualquer contexto (young, old ou agap). Falha se não estiver ligada em nenhum.

7.5 · note/warn/error/success (linha isolada)

note "rodada iniciada"
warn "assimetria detectada"
error "falta contrato escrito"
success "auditoria concluída"

8 · Cálculo de poder

0x0227: capacity(7) + support(5) + education(3) = 0..15
0x0228: resources(7) + legal(5)              = 0..12

ratio = poder / máximo
diff% = |ratio_young − ratio_old| × 100
  • 0–10% → EQUILIBRADA (verde)
  • 11–25% → LEVE (ciano)
  • 26–50% → MODERADA (amarelo)
  • 51–75% → ALTA (vermelho)
  • 76–100% → CRÍTICA (vermelho)

9 · Erros

O motor detecta e mostra linha aproximada:

  • Sintaxe — delimitadores, print"..." sem parênteses, DSL malformada.
  • Variável não declarada — sugere var young = 0x0227 ou o .set() correto.
  • Tipo — .power() em vez de .power (getter) etc.
  • Assertion — flag não garantida em nenhum contexto.
